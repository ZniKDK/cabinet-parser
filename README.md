# cabinet-parser

Собирает цены, наличие и сроки доставки **из личного кабинета** сайта поставщика или магазина по списку артикулов из Excel и складывает результат в Excel.

Подходит для сайтов, где обычный парсер не справляется:

- цена «для вас» видна только после входа в аккаунт;
- цена, остаток и срок доставки подгружаются скриптом после открытия страницы;
- на входе капча или код из SMS — можно войти один раз вручную, дальше парсер работает сам.

Под новый сайт код не меняется: описание сайта — это короткий YAML-файл с CSS-селекторами.

## Как это работает

```
Excel с артикулами ──► вход в кабинет (или сохранённая сессия)
                     ──► поиск артикула ──► страница товара ──► поля по селекторам
                     ──► Excel с результатом (сохраняется по ходу работы)
```

- **Настоящий браузер** (Playwright + Chromium): работает всё, что видит человек.
- **Сессия сохраняется** — повторный вход не нужен, меньше капч и подозрений.
- **Продолжение после сбоя:** при повторном запуске собираются только недостающие артикулы.
- **Повторы и снимки ошибок:** если страница не загрузилась, парсер пробует ещё раз, а снимок экрана кладёт в `errors/`.
- **Бережный режим:** пауза между товарами настраивается (не меньше 0,5 с).
- **Аккуратный Excel:** числа — числами (с ними можно считать), заголовок закреплён, у каждой строки статус и ссылка на товар.

## Быстрый старт (демо, без настроек)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python -m playwright install chromium

.\.venv\Scripts\python -m cabinet_parser demo            # добавьте --headed, чтобы видеть браузер
```

Демо поднимает встроенный магазин с кабинетом (`demo_shop/`), где цена видна только после входа, и собирает 6 артикулов:

```
[1/6] BG1001: ok
...
[6/6] BG7777: не найден

Готово. Всего артикулов: 6, уже были: 0, собрано: 5, не найдено: 1, ошибок: 0
Результат: data\demo_result.xlsx
```

## Свой сайт

1. Скопируйте `examples/site_template.yaml`, укажите адреса и селекторы (в шаблоне подробные комментарии).
2. Логин и пароль — в `.env` (образец — `.env.example`). Или без пароля: войдите руками один раз

   ```powershell
   .\.venv\Scripts\python -m cabinet_parser login --site examples\supplier.yaml --manual
   ```

3. Запустите сбор:

   ```powershell
   .\.venv\Scripts\python -m cabinet_parser run --site examples\supplier.yaml --input прайс.xlsx --output результат.xlsx
   ```

Ход работы печатается в консоль, подробный лог — `data/cabinet-parser.log`. Ctrl+C останавливает сбор, собранное сохраняется.

## Поля

| Параметр | Что значит |
|---|---|
| `selector` | CSS-селектор элемента |
| `title` | заголовок колонки в Excel |
| `type` | `text`, `money` (число с копейками), `int` |
| `wait` | ждать, пока скрипт страницы заполнит элемент |
| `attr` | взять атрибут (например, `href`), а не текст |
| `regex` | вырезать часть текста; группа в скобках — если нужна только она |

## Тесты

```powershell
.\.venv\Scripts\pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest
```

Сквозные тесты запускают настоящий Chromium на демо-магазине: вход, поиск, ожидание цены, «не найден», продолжение, повторное использование сессии, неверный пароль.

## Ограничения

- Используйте на сайтах, где у вас есть доступ к кабинету, и соблюдайте их правила. Обход защит от роботов в задачи инструмента не входит.
- Сайты меняют вёрстку — тогда правятся селекторы в YAML.

## Стек
